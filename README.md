# FontLabel

## 핵심 기능

### 폰트 폴더링

1. 현재 사용할 수 있는 폴더링 해서 보여준다.
2. 폴더에서 각 폰트 카드를 이동시킬수 있다.
3. 새로운 폴더를 만들어서, 폰트 카드를 이동시킬 수 있다.

### 폰트 라벨링

1. 폰트 카드에서 '+' 버튼을 눌러서 라벨을 추가할 수 있다.
2. 색상을 지정해서, 라벨 폴더를 만들 수 있다.
3. 추가된 라벨은 라벨 페이지에 새로운 폴더로 생성이 된다.
4. 기존에 존재하는 라벨 폴더로 이동시킬 수 있다.
5. 라벨에는 중복으로 폰트가 들어갈 수 있다.
6. 라벨링 한 폰트 카드의 정보는 캐시를 하여서, 성능 최적화를 한다.

### 검색 기능

1. 디렉토리 영역을 선택하고 폰트를 검색할 수 있다.
2. 디렉토리 영역에 경로를 입력해서 페이지 이동을 할 수 있다.

### 라벨 폴더 관리

1. 라벨 폴더를 삭제할 수 있다.
2. 라벨 폴더의 색상을 폴더 아이콘을 선택하여 변경할 수 있다.
3. 라벨 폴던 간 폰트 카드를 이동시킬 수 있다.

### 환경설정

1. 소스 폴더 페이지의 모든 동작을 초기화시킬 수 있다.
2. 라벨 폴더 페이지의 모든 동작을 초기화시킬 수 있다.
